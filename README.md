# Torn Companion - OC Utility Manager

Public userscript for Torn City faction OC 2.0 item management.

## Version
1.0.0

## Compatibility
- Tampermonkey
- TornPDA

## What it does
- Finds faction members missing required OC 2.0 items.
- Resolves member and item names.
- Checks faction armory stock.
- Shows the correct Armory category to open.
- Provides a user-triggered Give action for the selected member.
- Includes responsive mobile support for TornPDA.

## Install
Install the userscript from:
https://raw.githubusercontent.com/eKININJ4x/torn-oc-utility-manager/main/oc-utility-manager.user.js

## Updates
Tampermonkey uses the metadata file in this repository to check for newer versions automatically.

## Security
The Torn API key is stored locally by the userscript/browser and is sent only to the Torn API.

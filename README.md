# Torn Companion - OC Utility Manager

Public userscript for Torn City faction OC 2.0 item management.

## Version
1.1.0

## Compatibility
- Tampermonkey
- TornPDA

## What it does
- Finds faction members missing required OC 2.0 items.
- Resolves member and item names.
- Checks faction armory stock.
- Shows the correct Armory category to open.
- Provides a user-triggered Give action for the selected member.
- Includes responsive mobile support for TornPDA.

## Install
Install the userscript from:
https://raw.githubusercontent.com/eKININJ4x/torn-oc-utility-manager/main/oc-utility-manager.user.js

## Updates
Tampermonkey uses the metadata file in this repository to check for newer versions automatically.

## Security
The Torn API key is stored locally by the userscript/browser and is sent only to the Torn API.

## Torn Companion
Community tools for Torn City.

## Button colours
Open TC OC, select **Settings**, then use **Button colours** to choose a background and text colour. Preview changes before selecting **Save colours**. **Reset colours** restores the purple gradient and white text. Preferences are saved separately from your API key and persist through script updates in the same userscript/browser. Torn PDA uses the same controls.


## Move the button
Drag the dotted handle beside TC OC using a mouse or finger. Positions are saved through reloads and script updates, and adjusted to stay within the viewport when its size changes. The main button still opens the panel. With the handle focused, use arrow keys for small moves or Shift+arrow for larger moves. **TC OC → Settings → Reset position** restores the default location. Colour preferences and the API key are kept separately and preserved.

# Changelog

## 1.1.0 — 20 October 2026
- Adds a dedicated mouse/touch drag handle and keyboard movement for the TC OC button.
- Saves positions across reloads and updates, adapts them on resize, and keeps the launcher within the viewport.
- Positions the main panel near the moved launcher and adds Reset position in Settings.
- Preserves API keys, colours and existing OC item workflows.

## 1.0.4 — 20 October 2026
- Adds saved background and text colour controls for the TC OC button under Settings.
- Adds a colour preview, Save and Reset controls, and storage failure messages.
- Renames the API key toolbar button to Settings; API key controls remain available there.
- Keeps API access, item detection and the user-triggered Give flow unchanged.

## 1.0.3
- Highlights the required Armory category tab in green during the TC OC issue flow.
- Highlight follows Torn page re-renders and clears after issue/cancel.

## 1.0.2
Automatic-update verification release. No functional changes.

## 1.0.1
